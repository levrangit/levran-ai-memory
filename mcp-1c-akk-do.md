# mcp-1c-akk-do

## Назначение

Отдельный экземпляр MCP-сервера `mcp-1c` для конфигурации **1С:Документооборот (DO)** с расширением **DO_RAU**.

## Конфигурация

- Основная конфигурация: **DO**
- Расширение: **DO_RAU**
- Исходная выгрузка: `/home/leo/1c-dumps/MCP.7z`
- Распакованная исходная выгрузка: `/home/leo/1c-dumps/MCP`
- Рабочая чистая выгрузка: `/home/leo/1c-dumps/MCP_clean`
- Структура рабочей выгрузки: DO — корень dump, DO_RAU — вложенное расширение.

## MCP-сервер

Основной бинарник:

`/home/leo/mcp-1c/mcp-1c`

Рабочая конфигурация запускается с dump:

`/home/leo/1c-dumps/MCP_clean`

Для DO настроен HTTP bridge к опубликованной информационной базе:

`http://192.168.1.144:8080/DO/hs/mcp-1c`

## Важная архитектурная особенность

`mcp-1c` использует один dump-root для одной основной конфигурации с её расширениями.

Для DO рабочая структура поэтому организована как:

```
/home/leo/1c-dumps/MCP_clean/
└── DO/
    ├── Configuration.xml
    ├── ConfigDumpInfo.xml
    └── ...
    └── DO_RAU/
        ├── Configuration.xml
        ├── ConfigDumpInfo.xml
        └── ...
```

DO и DO_RAU не должны размещаться как две независимые соседние конфигурации в одном dump-root.

## Связь с живой базой

Windows:

- информационная база DO: `L:\AI\MCP\AKK\DO`
- Apache: `C:\Apache24`
- HTTP endpoint: `http://192.168.1.144:8080/DO/hs/mcp-1c`
- Apache слушает порт `8080`.

На Ubuntu `leosrv` MCP обращается к этому endpoint по LAN.

Этот экземпляр относится к контуру **АКК / Документооборот (DO + DO_RAU)** и является отдельным от экземпляра `mcp-1c-ogorodnik` для **ERP + ERP_RAU**.
